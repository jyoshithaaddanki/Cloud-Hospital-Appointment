# 🏥 Cloud-Based Hospital Appointment Management System

## 📌 About the Project

The **Cloud-Based Hospital Appointment Management System** is a simple web application that allows patients to book hospital appointments online. Users can enter their details, select a doctor, choose a date and time, and view their appointment status.

## 🎯 Objectives

* Make hospital appointment booking easier
* Reduce waiting time and paperwork
* Provide a simple and user-friendly interface
* Manage appointment details digitally
* Demonstrate the use of cloud computing and web technologies

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* Cloud Computing

## ✨ Features

* 👤 Patient details
* 👨‍⚕️ Doctor selection
* 📅 Appointment date selection
* ⏰ Appointment time selection
* 📋 Appointment details
* ✅ Appointment status
* 📱 Responsive design

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Open `index.html`.
4. Install the **Live Server** extension in VS Code.
5. Right-click `index.html`.
6. Select **Open with Live Server**.
7. The application will open in your web browser.
